## 何が起きたか

cold start（HP130/$80/3×3/素材0）から farm ×10 前後（cap7〜9・全て d7 で脱出）を回したあと、次の状態で
**前に進む手が無くなった**:

```
$14  S(小)14  M(中)0  L(大)0
設備: 魔力炉Lv1 / 作業台Lv1 / 研究机Lv1 / 錬金釜Lv0
見習いの杖: 未製作（コスト S15＋ゴブリンの牙×3。ゴブリンの牙は 10 個あるが 小結晶が 1 個足りない）
解放タスク: glen_1（小×15 納品）/ dag_wand（杖製作）/ dag_1（討伐・dag_wand の先）/
          orca_2・orca_2b（深度8/11 到達）/ liese_1・2（欠片納品）
```

- **見習いの杖**: S15 が要る。手持ち S14。**あと 1 個**。
- **小結晶を増やす手が全部塞がっている**:
  - `glen_1`（faucet）= 小×15 納品 → 手持ち S14 では出せない（＝欲しいものを対価に要求される循環）。
  - `60G→中結晶`（→崩して小×10）= $60 必要、手持ち $14。
  - 現金の唯一の増やし方 = モンスター素材の売却だが、d7 farm で採れて売れるのは `大ネズミの尾 ×4→14G` だけで、
    深度の窓がずれて枯れた（他の手持ち＝小さな牙／薄い翼膜／胞子嚢／鋭い爪 は売却オファーが無い）。
  - `orca_2`（深度8 で 大結晶×2＋炎欠片×2）= 杖なしの 3×3/HP170/Atk10 では d7 が壁で届かない。
  - `dag_1`（討伐10）= `dag_wand`（杖製作）の先にチェーンされていてロック。

→ **杖 ⇄ 小結晶 ⇄ 現金 ⇄ 深度8 ⇄ タスク がすべて相互ロック**。1 小結晶ぶんの差で詰み。

## なぜ Mode A（貪欲）では詰まないのか

貪欲エージェントは (a) 20〜25 周ぶんの farm loot を積む物量 (b) 売れる素材を片っ端から売る
(c) たまに序盤 RNG が ゴブリン多め／大ネズミの尾 多めの run を出す、で**確率的に**この谷を越える。
人力の 1 本勝負＋不利シード＋「作業台/研究机を先に建てて小結晶を使い切った」判断が重なると落ちる。
＝**再検証3/5 の D1/R2（cold-start 結晶詰み）と同じクラスの穴が、S2〜S14 を入れた後も“最序盤”に残っている**。

## 判定

- **Mode B 裏取りは未完（デッドロックで中断）**。Mode A の数字（21 周 d25 / 25 周 d29、2 本一致）を
  当面の**リファレンス値**として残す。
- **★S16（新規・要対応）**: cold-start に **無条件で踏める小結晶／杖の faucet が無い**（既存の faucet が
  すべて「小結晶・現金・深度8・杖」のいずれかを対価に要求し、それらが相互ロックしうる）。

## S16 の対策案（次サイクル）

いずれか 1〜2 個:
1. `glen_1`（最初の納品 faucet）の要求を **小×15 → 小×10** に（S14 で詰む今の穴をふさぐ）。
2. 見習いの杖のコストを **S15 → S12**（3×3→4×4 の一次投資の敷居を下げる。数値は仮）。
3. `dag_wand` を chain 先頭から外す or `dag_1`（討伐10）を `dag_wand` の前に（討伐は farm で自然達成＝
   無条件 faucet になる。報酬 中×3 が入れば崩して小×30）。
4. RewardScreen の入場料精算で「精算後に小結晶が n 個未満なら数個付与」の救済（詰み専用セーフティ）。

→ 3 が本命（討伐タスクは cold-start で必ず達成できる唯一の無条件アクション）。1 も安い。
