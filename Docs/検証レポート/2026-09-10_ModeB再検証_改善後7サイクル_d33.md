## 改善の判定

- ⭕ **N1（手動ステキャップ）修正を実地で確認。** サイクル6 で `statsPoint=61` を HP/Atk 中心に振り、`HP 880→1150`（旧 `HP_MAX=1000` 超）・`Atk 91→108`（旧 `OTHER_MAX=100` 超）・`Def 47→64`、**`statsPoint` は 61→0（全消費・死蔵ゼロ）**。ライブ確認 `ps.hp>1000 == True` / `ps.atk>100 == True`。壁が d31→d33 に動いた一因。改善前レポートの「中盤以降ステP報酬がほぼ空振り」は解消。
- ⭕ **O2（研究の Mana/Spd/Luc ゲートを取る）が効いて中盤が大幅前倒し。** 釜Lv2 到達直後の sweep で **研究 16→119 が1サイクルで開通**（改善前は同等の“117ノード一斉開放”がサイクル5）。壁は C2 d18（改善前 d12）・C3 d25（同 d19）・C4 d31（同 d22）と、**サイクル2〜4 で一貫して +6〜9 深度**先行。
- ⭕ **O7（釜Lv2前の炎フラグ faucet）解消を確認。** `wand_oak`（中結晶のみ）と作業台Lv2（`錆びた短剣×2 + 蜘蛛の糸×2`）を、**リーゼで炎エレメントの欠片を1個も買わずに**製作／建造 → サイクル3 で 5×5 到達。改善前は「炎欠片×2」ゲートが購入頼みの細い faucet だった。
- ⭕ **O6（釜Lv3 で欠片→エレメント精製）が機能。** サイクル5 で釜Lv3 建造後、`炎欠片×50→炎エレメント×10`・`風欠片×10→風エレメント×2` を精製（1アクション＝燃料1）。ギガ全体魔法（`大結晶×N + エレメント×3`）が facility 経由で取れるようになり、**研究フロンティアが改善前の「res238 で `CanAllocate` 全 false・小結晶1343死蔵」から「res252、残り約9ノード（うち大半が大結晶を溜めれば取れる）」へ**。机Lv3 も『若木の枝』(t2) で C7 に建った（改善前は t4 深層ドロップ待ちでデッド）。
- ⭕ **O1（研究深部に Def/Hp）を部分的に確認。** `nsp_Bulwark_*`（Def/Hp）が実在し、研究 Def は C2 で 33、C4 で 47 まで自然に伸びた（改善前の同時期は 30 前後）。ただし**深部フロンティアの Def/Hp はやはり早期に枯れ**、C4→C7 の研究 Def は 47 で頭打ち（以降の Def は N1 の手動ステPと armor 頼み）。最終 %DR0.24／不屈0.5／トゲ0.6 は乗ったが、鉄壁（固定軽減）・聖盾（バリア）は最後まで 0 のまま（下記 O8）。

- ⭕ **例外・error・warning ゼロ**（`read_console` types=[error,warning] で 0 件、全7サイクル・約25出撃・約200ウェーブ通して）。ソフトロック・進行不能なし。

## 新規の構造的所見

### バグ（コード）

- なし（今回の改善分は全て意図どおり動作。既知の `Transmute(part,times)` の times 非依存で燃料固定は不変＝仕様）。

### バランス / ツリー構造

- **O8（新規・O1 の続き）: 雷／光のエレメント欠片が facility ループで作れず、研究末端の 5ノードが恒久ロック。**
  `MonsterPartCatalog` に **雷属性・光属性のモンスター素材が tier2〜3 に1つも無い**（Fire=錆びた短剣/竜人の鱗/悪魔の角…、Wind=風切羽/若木の枝/石化の眼…、Dark=毒腺/古びた骨/呪われた指輪… はあるが Thunder/Light はゼロ）。錬金釜の欠片産出は素材の属性依存なので、**雷／光の欠片は精製できない**。トレーダー（リーゼ）の `$50→欠片×1` も**風固定**。結果、`Mega{Bolt,Shine}`・`Status{Shock,Dizzy}` 系の 5ノード（`中結晶×N + 雷/光エレメントの欠片×1`）が res252 時点で永久に取れない。O6 の精製経路は「モンスター素材にその属性がある」＝Fire/Wind/Dark にしか効かない。
  - 直し方の案: (a) tier2〜3 に雷／光属性のモンスター素材を1〜2種ずつ足す（`EnemyDataGenerator` + `MonsterPartCatalog`）、(b) リーゼの `$→欠片` オファーを属性選択制 or ローテーションに、(c) 釜Lv3 の精製を「任意属性の欠片5 → 任意属性のエレメント1」に緩める（属性の意味は薄まる）。
- **O9（新規・軽微）: 精製で余ったエレメントに sink が無い。** ギガ全体魔法は属性ごとに1ノードなので、その属性のエレメントは 3個あれば足りる。今回は炎エレメントを一括精製（欠片50→10）した結果、**炎エレメント 20個超が使い道なく死蔵**（最終 elem36）。精製は「欠片(所持−端数) を1アクションで」なので刻みにくい。UI で「今の研究に必要なぶんだけ精製」を出すか、エレメント→大結晶 or お金の逆変換オファーがあると無駄が減る。
- **O10（改善前 O6 の残り）: 大結晶が中盤〜深部の律速。** res241→252 の詰めは一貫して「11ノード → 数ノード」を大結晶で買う作業で、S/M からの `10:1` 変換を何十回も回した（1サイクルで glen `M10→L1` を 32回など）。錬金釜Lv3（t4→大×1・t5→大×3）と机Lv3（コスト0.6×）が揃うと楽になるが、そこまでは大結晶が細い。深部素材（t4/t5）を踏める頃には研究側がそれを待っている状態。
- **O11（O1 の具体化）: 防御特性の tier2-3（鉄壁＝固定軽減／聖盾＝バリア）が `大結晶×N` ゲートで最後まで開かない。** `BuildTraitColumn` の ring6-7 は `Sm(2+ring) + Md(1)`〜`大×N`。今回 %DR（見切り）と不屈は取れたが、固定軽減・バリアは C7 でも 0。深部の壁が「1発の大きさ」であるほど固定軽減・バリアが効くのに、そこが一番遠い。trait tier2-3 のコストを結晶のみ（欠片・大結晶を外す）にするか、ring を1つ内側に寄せる余地。

### 導線 / UX（バグではない）

- 研究画面に「次に開くには〈大結晶×3〉／〈雷エレメントの欠片〉が要る」の表示が無く、`foreach CanAllocate` を回して初めて frontier の中身が分かる（改善前レポートと同じ指摘。O6/O8/O11 全部これに当たる）。
- 錬金釜ハブUIに欠片→エレメントの「精製」行が出るのは確認できた（`level>=3` 分岐）。ただし「5の倍数で投入」が UI 任せなので、端数を持つと直感的でない（O9）。
