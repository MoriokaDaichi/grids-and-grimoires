## 所見

### R7-1. Mode B（手動）は Mode A（自動ハーネス）より深く行けなかった

- Mode A ×15（サイクル15）: farm×3→push **8→11→13→…→17→17→18**、HP435/Atk109/研究ステ69。
- Mode B 手動（本検証）: 同程度の run 数で **d12・HP280/Atk30/研究ステ10**。
- 理由: **中盤の素材経済（エレメント欠片・中結晶）がボトルネック**。作業台Lv2 は建ったが 樫の杖（tier2、
  M6＋炎欠片×2）が炎欠片切れで打てず、5×5 に届かない。研究の深いステノード（`Md(1)` コスト）も
  中結晶枯れで伸びない。Mode A の貪欲経済（サイクル1〜14 で作り込んだ）の方が、この帯を上手く回す。

### R7-2. 成長ループの“レート”が遅い

- `dag_grind` は 25 体撃破ごとに ステP+1。push 1周 ≈ 20〜30 体 ≈ +1 ステP/周。
- 大きな恒久ステ塊（orca 深度タスクの +5/+6/+8）は d15/d18/d20/d22 到達が前提だが、**d15 に届く前に
  ステが伸びない → d15 に届かない**、の弱い chicken-egg が d11〜15 帯にある。
- → 20 周でも +20〜30 ステP 程度で、d12 から d30 へ跳ぶには足りない。

### 到達見込み（Mode A ベース）

- Mode A ×15 = d18（まだ climbing）。**×20 なら ~d20〜22** と推定。
- **単発「完璧に回した強キット注入」＝ d26**（サイクル15、tier3 装備＋5×5＋研究フル＋orca 節目ステP）。
- **d30 を 20 周で自然到達するのは、現状の中盤経済では届かない。**

## d30 を「20周で」届かせるための案

1. **中盤のエレメント欠片 / 中結晶 faucet**（`TraderCatalog`）: liese の浅いタスクに欠片、dag/orca の
   繰り返しタスク or 中盤タスクに中結晶。＝作業台Lv2/Lv3・tier2/3 杖・深い研究ノードが“詰まらず”回る。
2. **成長ループのレートを上げる**: `dag_grind`/`orca_grind` の報酬を ステP+2〜3 / 撃破数を 25→20 に。
   or orca 深度タスクの解放を「その深度を1度でも通れば」に緩める（＝壁ちょうどで報酬が入る）。
3. **D: 6×6 グリッド**（tier3 杖）で AoE throughput を上げる（深部の同時4体を捌ける）。
4. `ResearchGraph` の深いステノードのコストを `Md(1)`→`Sm(n)` に（中結晶ゲートを外す）。

推奨: **1 ＋ 2**（中盤の詰まりを取る＋レートを上げる）。これで Mode A/B とも 20 周で d25〜30 帯に入る想定。
