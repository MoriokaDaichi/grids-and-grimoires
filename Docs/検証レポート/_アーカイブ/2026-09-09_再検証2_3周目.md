## 新規の所見

### R1. 研究が ~70ノードで頭打ち＝この先はエレメント欠片が要る
Def/HP/Spd の小ノードと MegaFire/MegaThunder を取り切ると、`CanAllocate` が全ノードで false に。GigaFire・状態異常特化などの大ノードは `requiredMaterials` に **エレメント欠片／エレメント** を要求し、欠片は「錬金釜Lv2（属性 tier2+ 素材→欠片）」か「精霊使いリーゼの特定交換（錆びた短剣×4→炎欠片 等）」でしか手に入らない。**研究机Lv1＋錬金釜Lv1 だけでは研究が中盤で止まる**。→ 4周目でリーゼ交換を回して欠片を作り、GigaFire 等を解禁して再測定する。

### R2. Lv2 設備の連鎖ゲート（前回検証 N2 の継続）— 新規敵保証で楽になったが「×3必要／×2/run」で足踏み
- 魔力炉Lv2：`M(6) + 鉄の兜×3`。鉄の兜はゴブリン戦士（debut 深度11）専用で、保証枠のおかげで **深度11 farm 1回につき確実に×2**。だが Lv2 は×3必要＝2回潜る必要。さらに `M(6)`＝中結晶6 が cold start では別途 glen_1（小結晶15→中結晶3）1回きりで足りず、中結晶がボトルネック。
- 錬金釜Lv2：`M(7) + 剛毛×3 + 古木の芯×2`。古木の芯は森の番人（debut 深度19）＝現状の壁の遥か先。**錬金釜Lv2 は事実上ロック**され、tier2 素材（剛毛・錆びた短剣・蜘蛛の糸・風切羽…）が変換できず貯まる一方。
- 提案：Lv2 建材の必要個数を×3→×2 に、または中盤素材（tier2）で開けられる別ルート／Lv2 の古木の芯要件を浅層素材に差し替え。

### C2 深層スケーリング（knee12→10 / slope0.5→0.4）の体感
再生のトルク（3.5/s）と合わせて、**深度9〜12 の farm 帰還時 HP が明確に高い**（2周目 d9=63/230 → 3周目 d11=341/360, d12=210/360）。ただし死亡深度は 13 のままで、C1（4×4）による「安全に潜れる深度」の底上げがメインで、スケーリング nerf 単独の寄与は切り分けにくい。
