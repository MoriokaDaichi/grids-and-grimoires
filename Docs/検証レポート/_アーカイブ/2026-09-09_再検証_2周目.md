## 入場料セーフティ（所見4対策）— ✅ 完全動作

| ステップ | 結果 |
|---|---|
| 所持金 15 → 出撃 | 通常どおり 15G 徴収（`EffectiveEntryFee(15)=15`）→ 所持金 0 |
| 所持金 0 → 出撃 | **無料入場**（`CanAffordEntry()=True`、`StartSortie` で徴収なし、所持金 0 のまま）。`DungeonManager.entryFeeOwed=15` を記録 |
| 深度5で脱出 → 報酬画面 | `RewardScreen`：`feeRecovered=15` / `feeSoldText="スライムゼリー ×2、薄い翼膜 ×2、大ネズミの尾 ×1"`。**戦利品を安い順に自動売却して15Gを精算** |
| 帰還（OnReturn） | 精算ぶん（スライムゼリー2・薄い翼膜2・大ネズミの尾1）は `pendingDrops` から差し引かれてインベントリに入らず、残り（大ネズミの尾1・毒針2・胞子嚢2）だけ付与。**所持金は 0 のまま（回収15 − 未払い15 = ±0）** |

「タダで潜り続けられるわけではないが、詰みは防ぐ」という設計どおり。`EffectiveEntryFee` は **所持金15以上で15、14以下で0**（境界＝15）。
- 小さな点：`feeSoldText` は `Populate()`（報酬画面 OnEnable）で確定するが、実際の `MoneyManager` の出し入れは `OnReturn`（帰還ボタン）で行われる。画面を見ずに帰還ショートカットを押しても整合するので実害なし。

## 新規の所見（改善の副作用・追加）

### N1. 新規敵保証で深度2〜5が「敵1種類固定」＝最弱スライムが枯れる（1周目所見の再掲・重要）
深度2〜5は 1体/ウェーブ。保証が debut 敵で1枠埋めるため RNG 余地ゼロ（深度2=コウモリ/3=大ネズミ/4=スズメバチ/5=キノコ人間 固定）。**スライム（index0）が抽選から外れ、スライムゼリーが深度1（50%）か深度6+のRNG枠でしか出ない**。魔力炉Lv1・マジックサークル・複数装備/タスクのコスト。今回も深度1 escape を回して確保する羽目に。
- 提案：保証を「1体ウェーブでは無効」または「debut敵＋RNG枠で最低2体」にする。あるいは EnemyCountFor の下限を深度2から2体にする。

### N2. 3×3 でも MegaFire と Flame(AoE) が同居できない
MegaFire は L字4セル（幅2×高3）、Flame は 2×2。3×3（9セル）に両方は物理的に不可。単体強化 or 範囲強化の二択が続く。tier2 杖（4×4）まで解消しない。→ 「まず杖」に加えて「杖 tier2 までの導線」も長い点は要検討。

### N3. 中盤の燃料デッドロックは健在（タスクで救われる）
杖製作前、小結晶を使い切って fuel 2・crystal 0 になり設備アクション不能に。`dag_2`/`orca_2` の報酬結晶で復帰。前回所見D（タスクが結晶のライフライン）は cold start でより顕著。
