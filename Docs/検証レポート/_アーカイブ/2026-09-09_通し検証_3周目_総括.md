# 全体総括（3周・約20出撃・150ウェーブ超）

## 到達点の推移

| | キット | プッシュ到達（力尽きた深度） |
|---|---|---|
| 1周目 | HP190 / Atk12、Fire+Wind（2×2） | 深度11 → 深度7（振れ幅大） |
| 2周目 | HP260 / Atk16 / Spd7、Flame（2×2）、研究37 | **深度7** |
| 3周目 | HP290 / Atk16 / **Def11** / Spd7、Flame（2×2）、研究47 | **深度11** |

**3周かけても `bestDungeonDepth` は 11 のまま。深度30は遠い。** 正攻法だと「浅層の名前つき泥→Lv2設備／杖」の泥運の壁と、下記のバランス構造で、深度10前後で足踏みになる。

## 安定性（バグ・クラッシュ）
- **例外・ソフトロック・進行不能は一度も無し。** 20出撃・150+ウェーブ、研究割当90回超、トレード両替50回超、設備建造4回、錬金変換多数、タスク受領6回、脱出・死亡・報酬の往復多数。高 `Time.timeScale`（25〜60）でも `BattleManager` の再入ガードは健全。
- EditMode 158/158 グリーン（前後で変化なし）。

## バランス／設計の所見（重要度順）

### 1. ★ ウェーブ間で HP が回復しない → 「最大HP」より「Def と殲滅速度」
プッシュの壁は HP190→290 でほぼ動かず（7〜11）、**Def 5→11 で 7→11 に動いた**。
HP はダンジョン開始時のみ全回復。深度1から無回復で連戦するため、「1ウェーブの被弾総量 × 到達深度」が最大HPを超えた時点で落ちる。最大HPを盛るのは"床"を上げるだけで、**効くのは (a) 1発の削りを減らす Def と (b) 敵が殴り返す前に倒しきる火力/範囲**。現状の「HP +10/pt、Def +1/pt」の振り分けUIだと、プレイヤーは直感的に HP を積んで壁にぶつかりやすい。

### 2. ★ グリッド枚数（＝杖）が実質の火力ゲート。研究で開けた上位魔法が置けない
杖なしの 2×2 に置けるのは Tier1 単体×2 または Tier1 AoE（Flame dmg4）×1 のみ。`MegaFire`(4セル) `GigaFire`(6セル) は**物理的に入らず**、研究で解禁しても戦力にならない。
→ 進行の主リソースは「研究」ではなく「作業台→杖でグリッドを広げること」。しかし作業台は tier1 でも導線が無く、研究机のほうが（タスクで深度到達すれば結晶が入るので）先に建ちやすい。**"まず杖"の導線**（チュートリアル・タスク・UI ヒント）が要る。

### 3. ★ Lv2 設備・杖の建材が「浅層の名前つき泥」で、泥運の壁になる
- 研究机 Lv1：毒針×4（大スズメバチ専用、深度4〜）→ 1周目に farm 3回外し、深度8〜9まで潜って解決
- 作業台 Lv1＋杖：ゴブリンの牙×7（ゴブリン専用、深度5〜）→ 3周目に farm 3回でも 0、未達
- 魔力炉/錬金釜 Lv2：鉄の兜、剛毛＋古木の芯 …（深度10前後の敵）
抽選は窓内の一様乱数（`EndlessWaveGenerator.PickIndices`）で、特定の1種を狙うと試行回数がかさむ。**「その深度で初めて窓に入る敵を毎ウェーブ最低1体保証」** などがあると、進行の詰まりが解消しやすい。

### 4. 入場料でお金が枯れ、「潜れない」に近づく（2周目→3周目で発生）
タスク報酬が現物中心で現金が細く、出撃 ×15G で所持金が入場料未満に。素材売却で復帰できるがUI/導線を知らないと詰みかける。「戻り時の一部返金」「所持金0なら無料」等のセーフティ検討。

### 5. farm の最適解が「安全深度で即脱出」＝テンポが単調
死亡で全ロストのため、`安全深度で脱出→強化→また同じ深度`の反復が最適。深く行くインセンティブ（深度ボーナス、深層限定の泥保証）が弱いと作業感が出る。

### 6. panic 脱出が間に合わないケース（＝深度7で満タンから即死）
深度6→7 のウェーブで HP260 が 1ウェーブで 0 になる抽選が実在（3周目 farm 2回目）。ウェーブ開始時点の HP割合ではなく、途中で撤退できない仕様なので、"入った瞬間に詰む"ウェーブが出うる。深度あたりの被弾総量の上限クランプや、ウェーブ開始前の敵編成プレビュー＋撤退があると理不尽感が減る。

### 7. 小
- 再生開始時に `EditorApplication.isPaused=true`（3周とも）。
- `Transmute(part, times)` は times 非依存で燃料2固定（まとめ変換が最適）。
- `PlayerStatus.AddStat` の引数は大文字 `"HP"/"Atk"/…`。小文字だと無反応（UI経由なら実害なし）。
- `TradePanel` 進捗テキストが前提未達タスクでも「納品可能」と表示。

## 検証ハーネス側のメモ（ゲーム挙動ではない）
- 戦利品付与は `RewardScreen.OnReturn()`（帰還ボタン）でのみ発生。`GamePhaseManager.ReturnToBuild()` 直呼びだと未付与。全周とも `OnReturn` を明示呼びして回収した。
- フェーズ進行は `EditorApplication.update` 上のフックで `ContinueRun/EscapeRun` を叩き、`Time.timeScale` 25〜60 で加速。バトルロジックには非干渉。

## 反映（2026-09-09 その3 / コード変更あり）

このレポート群のフィードバックから3点を実装（EditMode 158→166 グリーン）。詳細は
[DEV_LOG](../DEV_LOG.md) の「-3.」。

- **所見4（入場料でお金が枯れる）** → `DungeonEconomy.EffectiveEntryFee`：所持金が基本料金(15G)未満なら
  入場無料（後払い）。無料入場したぶんは **帰還時に戦利品を安い順に自動売却して15Gを精算**（`RewardScreen`。
  報酬画面に「入場料の精算：〇〇 ×N を売却（-15G）」の注記行。戦利品が15G分に満たなければ不足ぶんは免除）。
  タダで潜り続けられるわけではなく、潜れなくなる詰みだけを防ぐ。
- **所見3（浅層の名前つき泥が泥運の壁）** → `EndlessWaveGenerator.NewlyOpenedIndexFor` ＋ `PickIndices`：
  その深度で初めて抽選窓に入る敵を毎ウェーブ最低1体固定。毒針（debut 深度4）・ゴブリンの牙（debut 深度6）等が
  debut 深度の farm で安定して湧く。
- **所見1（ウェーブ間HP無回復）** → サステイン系アクセサリ10種を `GearCatalog` に追加。HP毎秒回復／ウェーブ突破時
  回復（固定・割合）の副効果。`PlayerStatus.RegenHealth`／`HealWaveTick`／`ApplyGearDelta`。UI表示は最大HPだけを
  積む導線のままなので、次周は振り分けUIの見せ方 or 深層HP逓減も検討。

**未対応**: 所見2（"まず杖" 導線）、所見5（farm テンポの単調さ）、所見6（panic 間に合わず即死）、
小（TradePanel 表示 / Transmute 燃料）。

**次周**: この3点を入れた状態で正攻法4周目 → 深度到達の推移を再計測（サステイン装備を積むと壁がどこまで動くか）。
