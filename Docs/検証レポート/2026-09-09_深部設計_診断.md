# 深部（d16→d25）設計 — 診断

- 日付: 2026-09-09 / 改善ループ サイクル13（深部設計フェーズ）
- 前提: サイクル1〜12 の改善＋ユーザー追加の `BuildAtkColumns`（Atk 小ノード放射カラム 100本）が入った状態。
- 方法: 再生モードで「投資段階を変えたキット」を注入して push、到達壁を測る（純ロジックは不変）。

## 到達壁 × 投資段階

| 投資段階 | キット | 到達壁（push 死）|
|---|---|---|
| cold-start 素 | HP170 Atk10 / 3×3・base魔法2 | **d8** |
| 中盤を回しきった | HP365 Atk24 / 5×5・GigaFire＋GigaThunder＋Mega×2・Lv2設備・再生のトルク | **d15** |
| **全投資**（研究 251ノード・Atk111ノード＝**Atk238**）| HP400 Atk238 Def20 / 5×5・Giga＋Mega・maxMana500 | **d20** |

**投資を青天井にしても壁は d20。**「reasonable な中盤キット（d15）」から「Atk を +200 以上、研究を全解放」しても **+5 深度**しか伸びない。

## d20 の壁の正体

Atk / HP 不足ではない（Atk238 でも d20）。**同時出現数 × 単体火力偏重**：

- `EnemyCountFor(20, cap6)` = 4体同時。`roster.Capacity`(=6) までは 5深度ごとに +1。
- d20 のスケーリング（テーパー後）: HP ×3.1 / Atk ×2.35 / Def ×2.5。
- 4体が毎ウェーブ同時に殴る → 1ウェーブの被弾総量が `WaveDamageCap`(0.85×maxHp) に張り付く。
  `WaveHealCap`(0.5×maxHp) では戻しきれず、数ウェーブで落ちる（＝R4 の意図どおり "必ず削り勝てる"）。
- Atk238 で1体は1〜2発で溶けるが、**単体魔法で4体を順に処理する間に4体が殴り続ける**。
  強AoE（GigaFlame 等）を2枚積めれば話は別だが、5×5＋現行シェイプでは Giga単体2＋Mega全体1 が限界。

## つまり深部の伸びしろが無い理由

1. **投資先が「Atk/HP を盛る」しか無い** → 同時4体の throughput 問題は解けない。
2. **tier3 装備・設備Lv3 が実質未到達**（作業台Lv3 の建材 `竜のうろこ` はドラゴン＝pool idx37＝debut 深度37）。
3. **グリッドは 5×5 で頭打ち**（`maxGridSize`）＝AoE を増やす余地が無い。
4. **深部到達それ自体の報酬が薄い**（orca_4 d15→ステP＋120G、orca_6 d20→レシピのみ）。

## 設計案（d16→d25 を「投資すれば届く」ようにする）

### A. 深部到達＝進行そのものを報酬に（`TraderCatalog`・低リスク）
orca の深度タスクを刻んで（d15 / d18 / d21 / d24 …）、各節目で**恒久ステータス塊**（ステP＋5〜10 or HP大アイテム）を出す。
「d20 に届いたら次の 3〜4 深度ぶんの体力が手に入る」＝深さ自体が成長ライン。エンドレスらしい。**戦闘数値に触らない。**

### B. tier3 装備・設備Lv3 を d18〜24 の素材ゲートに（`HideoutCatalog`／`TraderCatalog`・中リスク）
`竜のうろこ`(d37) 等を d20 前後で採れる tier 相当の素材へ差し替え（"-7." の Lv2 と同じ手法）。
tier3 杖／防具／アクセ、設備Lv3（研究コスト減・炉スロット増）で「d20 の壁を越えるための最後のひと盛り」を作る。

### C. 深部の同時出現数を寝かせる（`EndlessWaveGenerator`・中リスク・R1/R4 注意）
`DepthsPerExtraEnemy`(=5) を深部だけ伸ばす、or `roster.Capacity` 上限を実効的に下げる。
throughput 問題そのものを緩める。ただし「バーストの怖さ」を削りすぎると R1/R4 の再来になるので慎重に。

### D. 6×6 グリッド（tier3 杖）＋大型 AoE シェイプ（`MagicGridManager`／`MagicDataGenerator`・高リスク）
`maxGridSize` 6、tier3 杖で 6×6。GigaFlame＋GigaFire＋単体 が同居できる＝AoE throughput が上がって深部が伸びる。
全魔法アセット再生成を伴う（`MagicDataGenerator`）ので影響範囲が広い。

---

## 推奨

**A ＋ B を先に**（低〜中リスク・戦闘数値に触れない）。
- A で「d20 まで行けば、d24 まで戦える体力が手に入る」の階段を作る。
- B で tier3 装備／設備Lv3 という最後の投資軸を d20 前後に開ける。
- これで cold-start 素 d8 → 中盤 d15 → 全投資 d20 → **A/B 込みで d25 前後**まで、投資に比例した深さになる想定。
- C（同時数寝かせ）・D（6×6）は A/B を入れて再計測してから、まだ足りなければ。

## サイクル13 実施結果（A＋B、commit `f632dc8`）

- **A**: オルカの深度タスクを d15/d18/d20/d22/d25/d30 と刻み、恒久ステP を 5/5/6/8/8/12 に。
- **B**: 作業台Lv3 の建材 `竜のうろこ`(d37) → `竜人の鱗`(d13)。armor_plate も同様。
  新レシピ 2種（竜騎の杖 Atk+16／竜鱗の胸甲 Hp+60、竜人の鱗製、オルカ d18/d22 で解禁）。
- テスト 196→198 グリーン。

### 到達壁の再計測（投資段階別・push 死）

| 投資段階 | キット | 到達壁 |
|---|---|---|
| cold-start 素 | Atk10 / 3×3 | d8 |
| 中盤キット | Atk24 / 5×5・Lv2設備 | d15 |
| 研究フル | Atk238 HP400 / 5×5・Lv2設備 | d20 |
| **深部フル投資（A＋B）** | HP630 Atk248 Def28 / **作業台Lv3・tier3装備3種**・orca節目ステP+24・研究フル | **d23** |

**投資ラダーができた**: d8 → d15 → d20 → **d23**。A＋B で全投資の壁が **d20 → d23（+3）** に伸び、
各段階で「次を目指す投資先」がある状態になった。フェイルステートは健全（d23 で decisive death）。

### 残る頭打ち（d25+ に届かない理由）

**同時4体×5×5グリッドの throughput 上限**は A/B では解けない。d25 まで詰めるなら:
- **C**: `DepthsPerExtraEnemy`(=5) を深部（d22+）だけ 5→7 等に伸ばす（＝同時数の増えるペースを寝かせる）。
- **D**: `maxGridSize` 6・tier3杖で 6×6（AoE を1枚増やせる）。魔法アセット再生成を伴う。
- いずれも要判断。A/B の d23 で一旦区切り。

## サイクル14（ユーザー方針: 無限リソース → 恒久ステ → 深層 のループ）

**「中層で素材を集めて大結晶をステータスに変換をくりかえし、さらに深層／討伐系タスクを無限発生」** を実装（commit `d073912`）。

- **大結晶→ステP 変換オファー**（オルカ・常時＝繰り返し可）: 大×2→ステP+2 ／ ×5→+6 ／ 中×12→+1。
- **繰り返し討伐タスク**（`TraderTask.repeatable`）: 達成しても completedTaskIds に入らず、受取ごとに
  「前回受取からの累計撃破数」で進捗リセット＝無限受注。
  - `dag_grind`（25体ごと→中×3＋ステP+1）／`orca_grind`（40体ごと→大×1＋ステP+2、深度15で解放）。
- ハーネス: 大結晶→ステP 変換＋貯まったステPを毎周 HP/Def へ消費（＝income が生存力に回る）。

### Mode A ×14 の到達推移（`_ループ_2026-09-09_cycle14b_無限ループ_x14.md`）

farm×3(d7) → push **8 → 11 → 13 → 14 → …（中略）… → 15 → 14 → 15 → 17**。**周を重ねるほど深くなる**
（Atk 21→109、研究ステ64ノード、タスク受領19回、HP385/Def17）。run14 で d17（d15:61%→d17:21% で脱出）。
サイクル14a（ステP を貯めるだけ）は d13 で頭打ちだったのが、ステP を使うようにして解消。

**＝エンドレスの成長ループが成立**：farm → 繰り返しタスク／結晶→恒久ステ変換 → 深層 → 繰り返し、で
深さが伸び続ける。14周で d8→d17、まだ climbing。フェイルステートは健全（decisive death 複数）。

### まだ残る（C/D 領域）

- 単発の「強キット注入」壁は d23（サイクル13）。無限ループの自然到達は 14周で d17＝**周数を重ねれば d20+ へ**。
- d25 を「現実的な周回数で」届かせるには C（深部の同時数のペースを寝かせ）or D（6×6）。要判断。
