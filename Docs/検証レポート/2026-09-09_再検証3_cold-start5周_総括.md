- 日付: 2026-09-09
- 位置づけ: DEV_LOG「-5.」で先送りした **項目4「改善反映後の cold start 5周で深度推移を再計測（深度20 に届くか）」** の実施。
- 対象の改善: 「-5.」の R2/R3（Lv2 設備ゲートを浅層寄りに）／ R4（tier2 中位素材の売却口）／ R5（序盤の中結晶・お金を1本足す）。
- 方針: セーブ wipe 後の cold start から連続5周。資源注入なし・ゲームAPIのみ（振り分け／建造／製作／変換／研究割当／交換／依頼受領／出撃）。
- EditMode テスト: 検証前後とも **172 / 172 グリーン**（不変）。
- 実行: 再生モード。`EditorApplication.update` に自動ドライバを1本差し、ウェーブ突破ごとに HP割合と深度キャップで「進む／脱出」を自動判定、報酬画面は `RewardScreen.OnReturn` をリフレクションで明示呼び。戦闘は `Time.timeScale` 35〜45。ビルドフェーズの経済（振り分け・配置・建造・研究・交換・依頼）はスクリプトで貪欲に処理。

> **ハーネスの限界（結果を読む上での前提）**
> - プレイヤーの判断は「貪欲エージェント」による近似。とくに序盤の結晶配分は人間ほど上手くない。
> - 魔法のグリッド配置は greedy first-fit。回転は試すが、人間の手詰めより**パッキングが下手**（GigaFire＋大型AoEを4×4に同居させられない等）。
> - 「脱出」判定はウェーブ**間**でしか働かない（1ウェーブ内のバースト即死は拾えない）。

### 残る構造的な壁（＝「-5.」で解けていない所）

#### D1. ★ cold-start の結晶経済が脆く、配分を誤ると回復不能に近い
1回目のトライは **深度9でハードロック**した。原因の連鎖:
- **錬金釜Lv1 の tier1 変換は完全に燃料中立**：`part + 小結晶×2（＝燃料2）→ 小結晶×2`。`CauldronYieldMult(1)=1.0`／`FurnaceFuelPerAction(1)=2` なので、**Lv1 の錬金釜では素材を結晶に変えても経済が1ミリも増えない**（素材を捨てているだけ）。
- したがって cold-start の結晶収入は **有限な序盤タスク報酬（dag_1・orca_1・glen_1・dag_2・glen_2/3 の中結晶）を glen の 大→中→小 で崩したぶんだけ**。
- これを設備Lv1＋研究の安いノードに全部つぎ込むと、**杖（小×15＋ゴブリンの牙×3）が買えないまま結晶ゼロ**になる。杖が無い＝3×3のまま＝火力が伸びない＝壁が深度8〜9。
- そして**回復ゲートの orca_2 は深度10**。深度9で詰まったプレイヤーは orca_2（大結晶×2）に手が届かず、**中盤の結晶faucetが永久に開かない**。

2回目は「杖を最優先」に方針を変えたら普通に進んだ。つまり**game 側の導線次第**で、脆さは実在する。

#### D2. 「まず杖」導線が無い（既知・未実装）
D1 の分岐点はまさに「研究より先に見習いの杖を作るか」。CLAUDE.md にも `未実装` と明記済み。杖のゲート素材 **ゴブリンの牙**（ゴブリン debut 深度6）が、序盤の生存壁（〜深度8）とほぼ同じ深さにあるのも地味に効く（1周で×2しか出ず、farm を数回まわす）。

#### D3. 錬金釜Lv2 の `中魔力結晶×5` は依然ゲート
部材（蜘蛛の糸・剛毛）は「-5.」で浅くなったが、**中結晶×5 の faucet が無い**。3周目は「tier2素材を売って $146 → オルカで大結晶×1（$120）→ glen で 大→中×10」でギリギリ確保した。**大きな素材ストック＋$120 の大結晶買い**という細い一本道。ここを 中×3 くらいに緩めるか、中結晶の中盤faucet（例：deliverタスクの報酬）を足すと、3周目相当の開通がもっと自然になるはず。

#### D4. tier1 変換が黒字化するのは「錬金釜Lv2 ＋ 魔力炉Lv2」の両方が要る
`FurnaceFuelPerAction` は Lv1=2 / Lv2=1。tier1 変換（→小×2）は Lv2 魔力炉で初めて **-1 燃料 +小×2 = 純増+1**。3周目に両方 Lv2 にした瞬間、貯めていた 80個超の tier1 素材が一気に **S277** に化けて研究が 28→40→53 に伸びた。逆に言うと**それまでは素材がいくら積んでも結晶にならない**。

#### D5. ウェーブ内バースト即死（C2）は未解消
深度13以降、farm 中に「>50% → 死亡」を1ウェーブで食らうことがあり（今回2回、farm を没収）、ウェーブ**間**でしか働かない「脱出」では拾えない。`gg_minhpfrac` の記録でも深度12→13 の遷移で 42%→2% のような落ち方が観測された。

#### D6. Atk が伸びない
5周を通して Atk は **10→17**（+3は杖、+3は研究小ノード、+1は余りステP）。深度スケーリング（Atk+10%/実効深度）に対してプレイヤー Atk がまるで追いつかず、深部ほど殲滅が遅い→被弾総量が増える。深部の押しは Atk ではなく **GigaFire＋GigaThunck の高倍率2枚**が担った。研究ツリーの Atk 小ノードが割当可能になるのが遅い（親・中結晶ゲートの奥）。

#### D7. 4×4 に GigaFire と強AoE が同居できない
GigaFire（6セルの階段形）＋ MegaFlame（7）/ Flame（4）＋詰め物 が 16 セルに収まらず、押しは「Giga二枚（AoE無し）」か「AoE＋Giga一枚」の二択。tier2 杖の 5×5 で解けるはずだが、**作業台Lv2 が `竜人の鱗`（リザードマン debut 深度13＝バースト即死帯）待ち**で、5周では建たなかった。
（※ハーネスの greedy 配置は人間の手詰めより下手。実UIなら回転＋手配置で GigaFire＋MegaFlame＋α は入る可能性がある。）

## 各周の詳細

### 1周目（cold start）
- wipe直後: HP130/Atk7/Def5/Spd5、ステP10、$80、素材0、全設備Lv0、グリッド3×3。
- 振り分け HP+4/Def+3/Atk+3 → HP170/Atk10/Def8。3×3 に Flame＋Thunder＋Fire。
- **1トライ目（貪欲配分）**: 設備5つLv1＋安い研究36ノード（うち大半がマナ／ステ）に序盤タスク報酬の結晶を全部投入 → **杖が買えず結晶ゼロ**。壁 深度8〜9、orca_2（深度10）に届かず **ハードロック**（$47・S1・中結晶faucet無し）。→ この状態を「D1」として記録し、セーブを wipe して再スタート。
- **2トライ目（杖最優先に方針変更）**: 魔力炉→作業台→研究机→錬金釜 Lv1、**見習いの杖を製作（→グリッド4×4）**、サステインアクセ1個。farm を d6〜d8 で回してタスクを消化 → **push で深度10 到達 → orca_2 受領（大結晶×2）** → glen で崩して研究一気に開通（MegaFire/GigaFire/MegaThunder）。HP285/Atk16/Def14、研究27。
- **push: 深度11で戦闘不能。**

### 2周目
- farm d8〜d10（4×4＋Atk16＋6%ウェーブ回復で d8 が安定圏に）。econ は結晶枯れでほぼ空転（研究27→28）。
- **push で深度12 到達 → orca_2b 受領 → 再生のトルク（毎秒+3.5回復）装備**（繕いの腕輪 1.5/s を置換）。
- **push: 深度12で戦闘不能。** 経済は依然停滞（S9、中結晶faucet無し、研究28で頭打ち）。

### 3周目 ― 中盤ブレイクスルー
- farm d11。手動で **tier2素材を売却 → $146 → オルカ `120G→大結晶×1` → glen `大→中×10`** で 中結晶を確保。
- **錬金釜Lv2 建造**（中×5＋剛毛×2＋蜘蛛の糸×2）→ tier2素材変換で研究28→34、**魔力炉Lv2 建造**。
- 魔力炉Lv2 で **tier1 変換が黒字化**、貯めた素材が **S170** に。研究34→40、HP380/Def18。
- **push: 深度15で戦闘不能。**（壁が 12→15）

### 4周目
- farm d13 で **バースト即死→farm没収**（D5）。S170 を一部 中結晶に崩して中結晶ゲートの研究を解放 → 研究40→49（mg22＝Mega/Giga 系ほぼ開通）。HP395。
- Atk は 16 のまま（Atkノードが割当不可）。グリッドは4×4のまま（作業台Lv2 の竜人の鱗が d13 帯で取れず）。
- **push: 深度14で戦闘不能。**（3周目と同水準、分散内）

### 5周目
- farm d11〜d12 を3回（安定圏、没収なし）→ 貯めた素材を錬金釜Lv2で変換 → **S277**、研究53（mg24）、Def19/Spd8/Atk17。
- **push: GigaFire＋GigaThunder の二枚差し**（AoE無し・計13セル）で深部を押す → **深度16で戦闘不能。**

## 次にやるなら（優先度順）

1. **D1/D2: cold-start の結晶詰みを塞ぐ。** 案:
   - 「まず杖」導線（グリッドを広げる動機づけ）を入れる。少なくとも作業台Lv1到達時に見習いの杖を提示。
   - もしくは錬金釜Lv1 の tier1 変換を薄く黒字に（`CauldronYieldMult(1)` を 1.0→1.5、または `FurnaceFuelPerAction(1)` を 2→1）。これだけで「素材を結晶に換えて経済を回す」が Lv1 でも成立し、詰みが大幅に減る。
   - もしくは orca_2 の到達要件を 深度10→8 に（回復ゲートを壁より手前へ）。
2. **D3: 錬金釜Lv2 の `中結晶×5` を ×3 に、または中結晶の中盤faucet（deliverタスク報酬など）を1本。** 「素材を$146売って$120の大結晶を買う」細道に頼らず 3周目相当の開通が来るように。
3. **D6: Atk の伸び代。** 研究ツリーの Atk 小ノードをもっと手前（中結晶ゲートの前）に置く、または深度スケーリングの Atk 係数を少し寝かせる。
4. **D5: ウェーブ内バースト被弾総量のクランプ**（1ウェーブで最大HPの N% 以上は削れない等）。farm の没収事故が減る。
5. **D7: tier2 杖 → 5×5 への導線を浅く**（作業台Lv2 の `竜人の鱗` を 深度10〜12 の素材へ）。または Mega/Giga シェイプを 4×4 で AoE と同居できる形に。
6. これらを入れて再度 cold start 5周 → 深度推移を再計測（深度20 に届くか）。
